# 📚 Book Manager with GUI - Python Edition
An academic Python exercise — A GUI application for managing a book collection, built with `Tkinter`.

## 🎮 Description
A desktop GUI application built in Python as an academic exercise. It allows users to manage a personal book collection through a clean graphical interface. The application features:

* Add, view, and delete book entries
* Input fields for book details (title, author, etc.)
* Graphical user interface using Tkinter
* Persistent or in-session book list display
* Simple and intuitive layout

A great project for learning Python GUI development and basic data management.

---

## 🚀 Getting Started

### Prerequisites

* Python 3.7 or later
* `tkinter` (included by default with Python)

### Run the App

1. Clone the repository:

```bash
git clone https://github.com/IoannisKassios/Book_With_GUI.git
cd Book_With_GUI
```

2. Run the application:

```bash
python main.py
```

3. Use the GUI to add and manage your book entries.
